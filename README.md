# RIYASH PAY — Render Edition

The complete React + Firebase Render Edition is packaged in `riyash-pay-render.zip`.

## Deploy on Render

1. Open Render and choose **New > Blueprint**.
2. Select this repository: `MohammedRiyashB/oneupay`.
3. Render reads the root `render.yaml`, extracts the ZIP during build, and publishes the Vite app.
4. After deployment, configure Firebase as described in the ZIP's `README.md`.

The project archive is at [riyash-pay-render.zip](riyash-pay-render.zip).

## Important payment limitation

Payment verification is **manual only**, not automatic bank verification. A submitted UTR or screenshot is only a claim. Approve only after independently seeing the matching credit in your own bank/UPI app.
