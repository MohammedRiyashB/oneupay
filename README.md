# RIYASH PAY — Render Edition

The complete React + Firebase Render Edition is included in `riyash-pay-render.zip` at the repository root. Extract the ZIP before connecting the project folder to Render. See the ZIP's README.md for Firebase setup, Firestore rules, and Render deployment instructions.

Important: payment confirmation is manual only. Approve a payment only after independently seeing the matching credit in your own bank/UPI app.
